# Contributing Authentic Studio Vision Samples

Authentic Studio Vision and Studio Vision Pro project files are the most
valuable evidence available for understanding the Studio Vision file format.
Each sample can reveal structures, relationships, and version differences that
cannot be established reliably from speculation alone.

Phoenix is an open-source preservation and recovery project. Its goal is to
help musicians recover access to their own creative work by developing an
evidence-based understanding of these legacy formats.

## What kinds of files are helpful?

Many kinds of authentic files can contribute useful evidence, including:

- Studio Vision project files
- Studio Vision Pro project files
- Projects with digital audio
- MIDI-only projects
- Damaged or partially corrupted projects
- Files missing their filename extension
- Projects from different Studio Vision versions
- OMS Studio Setup files
- OMS Bundles
- Studio Vision preference files
- Official Opcode demo or tutorial projects

Even a file that appears broken, incomplete, or impossible to open may retain
valuable structural information. Please do not repair, convert, or otherwise
alter the only surviving copy of a file before preserving it.

## Before You Send a Large Collection

If you have dozens or hundreds of Studio Vision or Studio Vision Pro projects,
please contact the Phoenix project before uploading them.

A carefully selected subset of projects can often provide more useful evidence
than an entire archive. Depending on the current stage of research, the project
may recommend particular kinds of samples (for example, projects containing
digital audio, damaged projects, files from older Studio Vision versions, or
projects with unusual characteristics).

## Privacy

Never upload anything you are uncomfortable sharing. Project files can contain
personal names, track labels, musical performances, and other sensitive or
identifying information.

Before contributing, you may:

- Rename tracks to remove personal or sensitive information
- Remove copyrighted musical material
- Contribute small test projects instead of personal projects
- Contact the project privately before sharing sensitive material

Contributors are welcome to contact the project privately before sending
materials. Public posting is not required.

When modifying a project for privacy, preserve the untouched original
separately and explain what was changed in the contributed copy when practical.

## Copyright

Phoenix does not redistribute copyrighted music. Authentic project files
supplied for research are used only to improve Phoenix's understanding of the
file format. Contributors should submit only material they own or have
permission to share.

Official Opcode demo or tutorial projects can still provide useful evidence,
but their inclusion in research does not imply permission to redistribute
their copyrighted contents.

## Preferred preservation practices

When available, please preserve:

- Original filenames
- Finder Type and Creator metadata
- Resource forks
- Extended attributes
- Original folder structure

Avoid opening and resaving files in modern applications before preserving
them, since this may alter timestamps, filesystem metadata, or other evidence.

These details may contain important evidence about how Studio Vision, OMS, and
the classic Mac OS stored and related project data. Some modern transfer tools,
archive formats, filesystems, and cloud services may discard legacy metadata or
resource forks. Keep the original media or an unmodified archival copy whenever
possible.

## Useful accompanying information

Context can make a sample substantially more useful. If known, please include:

- Studio Vision version
- Macintosh model
- Mac OS version
- OMS version
- Whether digital audio is present
- Whether the project still opens
- Any missing files
- Any known history of the project

Approximate or incomplete information is welcome when clearly identified as
such. There is no need to guess at details you do not know.

## What Phoenix will do

Contributed samples are used to:

- Compare file structures
- Identify recurring patterns
- Validate parser behavior
- Improve recovery accuracy

Phoenix follows an evidence-first methodology. Findings are grounded in direct
observations and documented behavior, and the project avoids unsupported
assumptions about undocumented formats.

## Thank you

Thank you for helping preserve this history. Every authentic sample contributes
to preserving an important part of digital music history and improves the
prospect that musicians can regain access to work created with Studio Vision.
