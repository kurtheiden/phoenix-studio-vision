# Partial source-layout semantic bridge

The source-layout bridge retains incomplete semantic associations separately
from `Descriptor166` containers and export-capable session structures. It does
not change the established 166-layout parser or the 120-layout observer.

Ordinal association is a bounded engineering inference from SCHOOL PROJECTS
source/normalized object correspondence, preserved slot-label order, complete
framed neighborhoods and the established normalized ordinal model. It is not a
decoded pointer or a claim of universal Studio Vision compatibility.

## Positive subprofile

All existing 120-layout positive guards and layout-conflict refusal remain
required. The narrower bridge additionally requires:

- An immediately adjacent type-0x07 record of exactly 15 framed bytes. This is
  a defensive subprofile restriction, not a universal name-record meaning.
- Count-derived slot views starting at candidate +106, with 120-byte stride;
  raw labels start at view +15 and require a NUL inside both the view and initial
  candidate. The last view extends 31 bytes beyond the initial record: it is a
  correspondence view, not exclusive ownership of its opaque bytes.
- The corroborating first two label observations `Meter Track` and `Tempo
  Track`, represented as separate leading special bindings. Their source event
  interpretation and conductor bounds remain unestablished.
- An uninterrupted type-0x02/type-0x29 pair run ending at a framed type-0x00
  terminal, with uniquely bounded, nonoverlapping candidate neighborhoods.
- Pair count equal to the candidate count. Ordinary slot i binds to local pair
  i for i >= 2. Duplicate, empty and non-UTF-8 ordinary labels are retained.

Cardinality shortages refuse the whole association; no blank-slot dropping,
shifted ownership, filename/hash lookup or arbitrary marker acceptance occurs.
Every refused candidate remains explicit. No partial project is reported as
complete semantic recovery.

## Event and export boundary

Associated ordinary pairs are probed with the existing `validated_event_bounds`
helper. Only its success/refusal is retained; its Descriptor166 authority token
is not passed onward. A successful probe does not independently establish source
prefix semantics, event decoding, source conductor authority or readiness.
An unsupported suffix retains pair association while refusing event authority.

AppService publishes summary diagnostics, with bounded range/refusal details at
Full diagnostics level. It does not add semantic sequence DTOs, compatibility
profiles, capabilities, or export paths for these associations. The existing
bounded sequence manifest still requires `parse_project_166`; the source bridge
does not bypass that gate or supply guessed source event ranges to decoders.

## Private implementation evidence

Explicitly authorized SCHOOL PROJECTS validation observed 15 structural
candidates, eight internal semantic associations and 103 ordinary pair bindings.
Seven candidates refused: four count mismatches and three unsupported adjacent
type-0x07 sizes. Existing ordinary event-bound probes matched 102 and refused one.
Seven associated sequences match all their ordinary probes; none has complete
source conductor/event authority or export readiness.

The final `kickin'dance` pair is present and associated. Its existing terminal
probe refuses `InvalidTerminalGrammar` at `[279626,279633)`, with seven observed
zero bytes. This corrects the earlier terminal-filter count interpretation;
it does not authorize an alternate source termination grammar.

After constructed tests passed, a prospective check of the first exact Prologue
candidate returned `IncompleteNeighborhood`. The implementation was left
unchanged. This is not semantic Prologue support and does not revise its earlier
prospective structural-observer refusal history.

No ownership experiment, private MIDI reference or specimen MIDI export was
used. COMIC BOOK remains sealed for later prospective independent validation.
Public tests use synthetic structures; private checks are ignored by default
and require explicit environment paths outside Git.
